# Ruthwik Vanaparthy — Personal Portfolio

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-6366f1?style=for-the-badge&logo=github)](https://vanaparthy-ruthwik.github.io/)

A premium personal portfolio website for a Data Analyst, AI/ML Enthusiast, and Vibe Coder.

## Live Site
[https://vanaparthy-ruthwik.github.io/](https://vanaparthy-ruthwik.github.io/)

## Tech Stack
- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, glassmorphism, animations
- **Vanilla JavaScript** — No frameworks, pure performance

## Features
- Dark premium design with glassmorphism
- Typing animation in hero section
- Scroll-triggered reveal animations
- Mobile-first responsive design
- Project filtering
- Contact form with validation
- Back-to-top button
- SEO optimized

## Sections
1. Hero — Name, roles, CTA buttons, social links
2. About — Introduction, career objective
3. Skills — Programming, Data, AI/ML, Web, Tools
4. Projects — Track My Bus, RAG Chatbot, Shoes E-Commerce, Student Portal, Faculty Hub
5. Education — Vaagdevi College of Engineering, B.Tech CSE (AI & ML)
6. Experience — Internship placeholders
7. Certifications — Cards with placeholders
8. Achievements — Hackathons, awards, leadership
9. Research — Research projects and interests
10. Resume — PDF viewer and download
11. Contact — Form + social links
12. Footer

## Setup
1. Clone the repo
2. Add `assets/resume.pdf`
3. Add `assets/images/profile.jpg`
4. Update placeholder text throughout `index.html`
5. Deploy to GitHub Pages
